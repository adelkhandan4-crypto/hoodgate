# Быстрое обновление контракта HoodGate

Настройки находятся в `public/token.json`. Контракт и X пока пустые.
Шапка и страница Token читают этот файл при открытии и каждые 5 секунд,
пока вкладка видима. Полный адрес можно скопировать кнопкой в шапке.

Из папки проекта:

```powershell
node scripts/update-contract.mjs 0xВАШ_АДРЕС_ИЗ_40_HEX_СИМВОЛОВ
node scripts/update-contract.mjs --clear
node scripts/update-contract.mjs --twitter https://x.com/ВАШ_АККАУНТ
```

Первая строка — шаблон: подставьте настоящий адрес. Скрипт проверяет его
формат, сохраняет остальные поля и атомарно заменяет JSON. Неверный адрес
не перезаписывает действующие настройки. Можно также редактировать JSON напрямую.

## После размещения на сервере

Обновлять нужно именно файл, который сервер отдаёт по `/token.json`.
В сборке проекта это `dist/client/token.json`, если при размещении не задан
другой каталог статических файлов:

```sh
node scripts/update-contract.mjs 0xВАШ_АДРЕС --file /полный/путь/к/token.json
```

Пересборка для такой замены не нужна. Для `/token.json` отключите кеширование
на сервере и CDN (`Cache-Control: no-store`). Пять секунд — интервал опроса
открытой вкладки, а не гарантия времени SSH-подключения или ответа сети.
При временном сбое страница сохраняет последние корректные настройки.

Этот адрес отображает токен проекта. Он не меняет адреса платёжных контрактов,
реестра агентов или USDG и не включает операции с деньгами.
